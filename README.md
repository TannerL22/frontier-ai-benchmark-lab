# Frontier AI Benchmark Lab

**An auditable, reproducible research platform for independent frontier-AI model comparisons.**

![Python](https://img.shields.io/badge/Python-3.10%2B-blue?logo=python) ![Stage](https://img.shields.io/badge/status-research%20prototype-64748b)

This new repository is being initialized with the complete v5.1 research package: eight model variants, 57 benchmark rows, 304 original model-score observations, three ranking approaches, historical validation, regression tests, and a Streamlit dashboard.

**Hosting:** GitHub Pages supports static sites only; it cannot run Streamlit's Python backend. Deploy the interactive application to [Streamlit Community Cloud](https://share.streamlit.io/) using `main` / `app.py` once the source files are in place.

**Research caution:** The two new Muse variants each have only ten independently published benchmark observations. Rankings are provisional and the index scale is not a percentage of intelligence. The project preserves frozen historical results and separates independent evidence from publisher composite indices.

Full documentation, setup instructions and deployment guidance will appear here as the source package is committed.
