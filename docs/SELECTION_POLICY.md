# Observation selection and correction decisions

The v5.2 release describes **frozen reported configurations**, not an operational claim about the best system available today. No universal promotion threshold is inferred from row counts. Sparse systems have source-specific primary comparisons, and all system-level conditions are inspected before any controlled-comparison claim.

1. Carry forward the original v5.1 chosen configurations as descriptive evidence, with unknowns and inherited verification labels visible. Historical files are not patched.
2. Add previously omitted cells only when the source establishes the same task version, metric column and named system. D001 restores FrontierCode 1.1 Main Score 50.9 for Fable Medium / Claude Code and 50.2 for Sol Medium / Codex. Main Score is a weighted rubric result, not the separate pass-rate column.
3. Do not select the largest reported variant after seeing its value. D002 retains Agent Arena Opus High 13.93 and records Max 17.29 as an excluded alternative. The live-session populations differ; replacing High with Max would not establish an equal-population comparison.
4. Keep reconstructed values distinct from direct numerical observations. Store component URLs, rounded values, task counts and the weighting formula. Preserve publisher-under-review labels, and exclude those tasks by default in primary comparison/aggregation views.
5. Retain publisher composites as external context, never additional constituent observations. Source overlap prevents agreement from establishing independent validation.
6. Publish every inclusion/exclusion with a dated decision and review state. A source update proposes a new evidence release; it does not mutate a frozen observation.

For a future controlled study, qualify runs prospectively using fixed endpoints/snapshots, reasoning, harness/tools, retry/fallback and resource budgets. Distinguish unknown comparability from documented incompatibility. Until those conditions are established, the result remains descriptive evidence. A universal aggregate remains an optional conditional experiment.
